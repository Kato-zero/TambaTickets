# Passly PWA

This is the mobile-first Passly Progressive Web App.

## Run
Serve this folder over HTTP/HTTPS (service workers do not run from `file://`). For example, deploy the folder to Vercel, Netlify, GitHub Pages, or any static HTTPS host.

## Install
- Android/Chrome: use the Install prompt or browser menu.
- iPhone/iPad: Safari → Share → Add to Home Screen.

The app uses an iOS-style bottom tab architecture on small screens, safe-area support, standalone display, offline shell caching, local persistence for demo state, and inline SVG icons.
